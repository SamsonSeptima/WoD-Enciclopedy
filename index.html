О библиотеке

Два тома, один репозиторий

статический сайт

Два тома лежат рядом в одном репозитории. Корневой индекс — общая точка входа; каждый том ссылается на него через ../index.html. Внутри — свои стили, поиск, бестиарий, лист персонажа и сохранения.

Каждый том самостоятелен: свои правила, инструменты и данные. Никакой серверной части, сборщика или базы данных нет — только HTML, CSS и JavaScript.
